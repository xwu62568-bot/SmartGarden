# 屋主模式 - 灯光设备详情页设计

## 目标

基于 Stitch 原稿 `屋主模式 - 灯光设备详情页`，在现有 Web 仓库中完成一版高保真静态复刻。该页面只服务灯光设备详情；后续喷泉等非灯光设备使用独立设计和实现，不在本次范围内。

## 范围

- 复刻灯光设备详情页的视觉层级、布局和主要控件
- 保留本地交互状态：开关、亮度、色温、色彩选中态
- 复用现有路由 `/owner/devices/:deviceId`
- 只对灯光设备渲染完整详情页
- 非灯光设备继续显示基础详情，不做本次视觉升级

## 页面结构

1. 顶部栏
- 返回按钮
- 设备名称
- 在线状态
- 设置按钮

2. 主控制区
- 中央灯光图标与绿色光晕
- 圆形电源按钮
- 开关状态文案
- 亮度滑杆与百分比

3. 灯光专属控制
- 色温切换：暖白、自然白、冷白
- RGB 色彩选择条与当前色预览

4. 设备信息区
- 所属区域
- 当前计划
- 所属场景标签

5. 快捷操作区
- 倒计时关闭
- 加入场景
- 设置计划
- 运行记录

## 交互约束

- 本次只做前端静态/本地状态交互，不接后端
- 顶部返回跳回 `/owner/devices`
- 主按钮切换开关状态
- 滑杆更新亮度文案
- 色温和 RGB 仅体现选中态，不做真实灯效

## 代码边界

- `OwnerDeviceDetailPage.tsx` 负责根据 `deviceId` 分支渲染
- 灯光详情所需 mock 数据放在 `src/shared/mock/owner.ts`
- 详情页样式继续集中在 `src/shared/styles/global.css`
- `OwnerShell.tsx` 负责设备详情页的滚动容器和底部 tab bar 行为

## 验证

- 新增或更新针对灯光详情页的页面测试
- 构建通过 `npm --prefix apps/web run build`
